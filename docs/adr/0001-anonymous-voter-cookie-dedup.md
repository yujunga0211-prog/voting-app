# 익명 Voter ID 쿠키 + DB UNIQUE 제약으로 중복 투표 방지

로그인 없이 중복 투표를 막기 위해, 첫 투표 시 무작위 `voter_id`를 `httpOnly`·`sameSite=lax`·1년짜리 쿠키로 발급하고 `votes`에 `UNIQUE(poll_id, voter_id)` 제약을 건다. 쿠키 확인만으로는 요청을 직접 보내 우회할 수 있어 서버(DB)에서 강제하며, 같은 `voter_id`로 결과 화면의 "내 선택"도 표시한다.

## Consequences

- 시크릿 창, 다른 브라우저, 쿠키 삭제로 쉽게 우회된다. 공정성이 중요한 투표에는 쓸 수 없다. 강한 보장이 필요해지면 로그인 기반 1인 1표로 바꿔야 하며, 이는 Voter의 정의 자체를 바꾸는 변경이다.
