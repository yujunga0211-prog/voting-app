# Results는 Open Poll에서는 투표한 Voter에게만, Closed Poll에서는 누구에게나 공개

결과를 먼저 보고 한쪽으로 쏠리는 투표(밴드왜건 효과)를 줄이기 위해, Open Poll의 Results는 해당 Poll에 Vote를 한 Voter에게만 보인다. 이를 지키기 위해 결과 전용 URL(`/polls/[id]/results`)을 두지 않고 `/polls/[id]` 하나가 Voter 상태에 따라 투표 폼 또는 결과를 렌더링하며, 홈 목록에도 득표수·총 투표 수를 표시하지 않는다(질문 문장과 시각만).

**개정(마감 기능 추가 시)**: 밴드왜건 효과는 투표가 진행 중일 때만 문제가 되므로, Closed Poll의 Results는 투표하지 않은 방문자를 포함해 누구에게나 보인다. 투표하지 못한 사람도 결과를 확인할 수 있게 하기 위해서다. 마감 시각이 없는 Poll은 영원히 Open Poll이므로 계속 투표한 Voter에게만 보인다. "마감 후에만 공개(투표한 Voter도 마감 전에는 못 봄)"도 검토했지만, 투표 직후 결과를 보는 경험을 잃는 대가가 커서 택하지 않았다.
