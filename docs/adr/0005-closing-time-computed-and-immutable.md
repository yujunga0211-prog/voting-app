# 마감은 저장된 마감 시각으로 계산하고, 생성 후 바꿀 수 없다

Poll의 Open/Closed 상태는 DB에 저장하지 않고 요청마다 `closes_at`과 현재 시각을 비교해 계산한다(`now() >= closes_at`이면 Closed). 그래서 마감을 처리하는 cron·배치 작업이 필요 없고, 폼을 연 채로 마감 시각이 지나도 투표 Server Action이 서버에서 거부한다. 만든 사람을 식별할 수 없으므로(ADR-0004) 마감 시각은 생성할 때 한 번 정하고 연장·조기 마감은 제공하지 않는다. 이를 허용하려면 Creator 개념과 비밀 관리 링크가 필요한데, 이는 별도 기능으로 미룬다. 마감 시각은 선택 사항이라 기존 Poll(마감 시각 없음)은 그대로 Open Poll로 남는다.
